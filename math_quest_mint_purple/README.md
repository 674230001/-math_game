# Math Quest — Mint + Purple Edition

โปรเจกต์ตัวอย่าง UI ใหม่ ผสมสีเขียวมิ้นต์/ครีม กับม่วง/ส้ม ให้ความรู้สึกเป็นเกมฝึกคณิตศาสตร์

## ไฟล์หลัก
- `index.php` หน้า Dashboard
- `quiz.php` แบบทดสอบตัวอย่าง พร้อมให้ XP เมื่อตอบถูก
- `scores.php` หน้าคะแนนและความคืบหน้า
- `admin.php` หน้าตัวอย่างจัดการโจทย์ เพิ่ม/ลบโจทย์
- `assets/style.css` ธีม responsive

## วิธีเปิดด้วย XAMPP
1. แตก ZIP แล้วนำโฟลเดอร์ `math_quest_mint_purple` ไปไว้ใน `C:\xampp\htdocs\`
2. เปิด Apache ใน XAMPP Control Panel
3. เข้า `http://localhost/math_quest_mint_purple/`

## หมายเหตุสำคัญ
นี่เป็นโปรเจกต์ตัวอย่างที่สร้างใหม่จากแนวทาง UI ที่เลือก ไม่ใช่การแก้ไขโค้ดต้นฉบับใน GitHub เพราะไม่สามารถดึงไฟล์ repository ต้นฉบับเข้ามาในสภาพแวดล้อมนี้ได้
คะแนนและโจทย์หน้า Admin ในตัวอย่างนี้เก็บใน PHP session เพื่อสาธิตหน้าตาและ flow เท่านั้น ยังไม่ได้เชื่อม MySQL หรือระบบล็อกอินจริง
