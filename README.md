# Math Quest — Dark Coral Edition

โปรเจกต์เว็บไซต์ฝึกทักษะคณิตศาสตร์ในรูปแบบเกม ออกแบบ UI ใหม่ด้วยธีมสีดำเข้ม แดงคอรัล และเขียวมิ้นต์ ให้ดูทันสมัย รองรับการใช้งานทั้งคอมพิวเตอร์และโทรศัพท์มือถือ

## ฟีเจอร์หลัก

- **หน้า Dashboard:** แสดงคะแนนสะสม เลเวล และหมวดหมู่โจทย์คณิตศาสตร์
- **หน้า Quiz:** แบบทดสอบคณิตศาสตร์ พร้อมตัวเลือกคำตอบและระบบสะสม XP
- **หน้า Scores:** แสดงคะแนนสะสมและความคืบหน้าของผู้เล่น
- **หน้า Admin:** เพิ่มและลบโจทย์คณิตศาสตร์ตัวอย่าง
- **Responsive Design:** ปรับหน้าจอให้เหมาะกับขนาดอุปกรณ์ต่าง ๆ

## เทคโนโลยีที่ใช้

- PHP
- HTML5
- CSS3
- PHP Session

## โครงสร้างโปรเจกต์

```text
math_quest_sunset_dark/
├── index.php

├── scores.php
├── admin.php
├── README.md
└── assets/

```

## วิธีติดตั้งและเปิดใช้งานด้วย XAMPP

1. ดาวน์โหลดและแตกไฟล์ `math_quest_sunset_dark.zip`
2. คัดลอกโฟลเดอร์ `math_quest_sunset_dark` ไปไว้ใน `C:\xampp\htdocs\`
3. เปิดโปรแกรม XAMPP Control Panel
4. กด Start ที่ Apache
5. เปิดเว็บเบราว์เซอร์และเข้า URL:

   `http://localhost/math_quest_sunset_dark/`

## หมายเหตุ

โปรเจกต์นี้เป็นเวอร์ชันตัวอย่างที่สร้างใหม่เพื่อสาธิตการออกแบบ UI และการทำงานเบื้องต้น ข้อมูลคะแนนและรายการโจทย์ตัวอย่างใช้ PHP Session โดยยังไม่ได้เชื่อมต่อฐานข้อมูล MySQL หรือระบบเข้าสู่ระบบจริง

หากต้องการใช้งานจริง ควรเพิ่มฐานข้อมูล MySQL ระบบสมาชิก และระบบจัดการสิทธิ์ผู้ดูแลระบบ
